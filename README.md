# 私铁经营模拟（暂名）

日本式私营铁路经营与城市发展模拟。TypeScript + three.js + Vite，手机优先。

## 在手机上试玩（本地局域网）

```bash
npm install
npm run dev
```

终端会显示 `Network: http://<电脑IP>:5173/`，让手机和电脑连同一个 Wi-Fi，用手机浏览器打开这个地址即可。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发服务器（局域网可访问） |
| `npm test` | 模拟核心的无头测试 |
| `npm run typecheck` | 类型检查 |
| `npm run build` | 生产构建，输出到 `dist/` |

## 操作

| 手势 | 作用 |
| --- | --- |
| 单指拖动 | 移动地图 |
| 双指捏合 | 缩放 |
| 双指旋转 | 旋转视角（松手吸附到四个方向，可在设置中关闭） |
| 点击 | 选择地块（再点空白处关闭面板） |
| 长按 | 查看地块详情 |

桌面：左键拖动移动，滚轮缩放，右键或 Shift+左键拖动旋转，Q/E 旋转 90°，方向键/WASD 移动，+/- 缩放。

## 目录结构

```
src/
  config.ts        可调参数（数据驱动）
  sim/             模拟核心：纯逻辑，可在 Node 中测试，不依赖 three.js / DOM
    map/           地图数据格式、MVP 地图布局与生成、查询
  render/          three.js 渲染：地形、水面、树木、道路、车站、相机、拾取
  input/           手势识别（纯逻辑）
  ui/              面板、设置、提示
tests/             vitest 无头测试
```
