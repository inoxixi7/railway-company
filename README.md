# 私铁经营模拟（暂名）

日本式私营铁路经营与城市发展模拟。TypeScript + three.js + Vite，手机优先。

> `rewrite` 分支：按新的方向从零重写（自由铺轨、日历与运行两个时钟、新界面）。目前完成第 1 步。旧版在 `master`。

## 在手机上试玩（本地局域网）

```bash
git fetch && git checkout rewrite
npm install
npm run dev
```

终端会显示 `Network: http://<电脑IP>:5173/`，让手机和电脑连同一个 Wi-Fi，用手机浏览器打开这个地址即可。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发服务器（局域网可访问） |
| `npm test` | 无头测试 |
| `npm run typecheck` | 类型检查 |
| `npm run build` | 生产构建，输出到 `dist/` |

## 操作

| 手势 | 作用 |
| --- | --- |
| 单指拖动 | 移动地图 |
| 双指捏合 | 缩放 |
| 双指旋转 | 旋转视角（松手吸附四个方向，可在设置中关闭） |
| 点击 | 查看地块（再点空白处关闭面板） |
| 长按 | 查看地块详情 |

顶栏右侧三个按钮：暂停、正常（1 天 ≈ 5 秒）、快进。「更多」里有回到小镇、旋转视角、设置（浅色/深色主题、旋转吸附、省电模式、帧率）。

桌面：左键拖动移动，滚轮缩放，右键拖动旋转，Q/E 旋转 90°，方向键/WASD 移动，+/- 缩放，空格暂停。

设计文档见 `docs/design.md`，开发须知见 `CLAUDE.md`。
