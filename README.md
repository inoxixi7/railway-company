# 私铁经营模拟（暂名）

日本式私营铁路经营与城市发展模拟。TypeScript + three.js + Vite，手机优先。

## 在手机上试玩（本地局域网）

```bash
npm install
npm run dev
```

终端会显示 `Network: http://<电脑IP>:5173/`，让手机和电脑连同一个 Wi-Fi，用手机浏览器打开这个地址即可。

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发服务器（局域网可访问） |

| `npm run build` | 生产构建，输出到 `dist/` |

## 玩法（第 2 步）

1. **铺轨**：在地图上拖动画线（8 方向，转弯自动生成曲线），松手后可继续从末端画；草案显示长度、造价、工期、构造（地面/高架/桥梁/隧道）和问题。可切换复线/单线，可撤销。画到东侧终点站西端即接入。确认后进入施工期。线路只有一条，之后从两端延长。
2. **车站**：点线路上的直线段（东西或南北向），选一面一线 / 相对式 / 岛式。
3. **基地**：点某个车站的一侧建车辆基地（固定规格，只能一个）。
4. **运营**：设定各时段发车间隔，购买列车（钢制通勤车、木造电车，可选节数）；系统按间隔自动排班、出入库。

时间：顶栏「速度」可选暂停、×1（1 秒 = 1 分钟）、×4、×16、×60、×360、×1440。切到后台自动暂停。

## 操作

| 手势 | 无工具时 | 铺轨工具中 |
| --- | --- | --- |
| 单指拖动 | 移动地图 | 画线 |
| 双指捏合 | 缩放 | 缩放 |
| 双指旋转 | 旋转视角（松手吸附四个方向） | 同左 |

## 目录结构

```
src/
  config.ts        可调参数（数据驱动）
  sim/             模拟核心：纯逻辑，可在 Node 中测试，不依赖 three.js / DOM
    map/           地图数据格式、MVP 地图布局与生成、查询
    track/         线形（8 方向 + 圆曲线）、纵断面（坡度、桥隧）
    rail/          线路、车站、车辆基地、车型目录
    ops/           运营拓扑（闭塞、单线区间）与列车运行（安全 + 排班）
    world.ts       游戏状态与固定步长模拟（1 步 = 1 秒）
  render/          three.js 渲染：地形、水面、树木、道路、车站、相机、拾取
  input/           手势识别（纯逻辑）
  ui/              面板、设置、提示
tests/             vitest 无头测试
```

## 调度第一层（安全）的做法

- 线路切成互斥资源：车站股道、复线自动闭塞区间（≤ 800 m）、单线区间（两个会车点之间整段）、复线终点站咽喉、出入库线。资源同一时刻只属于一列车。
- 单线区间与对面会车点的股道**原子预约**：要么一起锁定，要么都不锁。
- 列车按制动曲线行驶，永远能在进路终点前停下；另有物理保护：不接近同一股道上前车的车尾。
- **防死锁**：中间的两股道车站按方向使用股道（下行 1 番线、上行 2 番线），整条线就成为一个「环」；线上列车数限制在环的位置数 − 1 以内，保证永远有空位、总有列车能前进。
- 无头测试覆盖：复线、单线、一面一线中间站、停运回库后资源全部释放、运营中向两端延长线路。

## 暂定数值

造价、工期、曲线半径、闭塞长度、车辆基地规格、停车与折返时间、各时段默认间隔等都在 `src/config.ts`，均为暂定，待调。
