# 私铁经营模拟（暂名）

日本式私营铁路经营与城市发展模拟。TypeScript + three.js + Vite，手机优先。

> `rewrite` 分支：按新的方向从零重写（自由铺轨、日历与运行两个时钟、新界面）。目前完成第 1、2 步。旧版在 `master`。

## 在手机上试玩（本地局域网）

```bash
git fetch && git checkout rewrite
npm install
npm run dev
```

终端会显示 `Network: http://<电脑IP>:5173/`，让手机和电脑连同一个 Wi-Fi，用手机浏览器打开这个地址即可。

## 玩法（第 2 步）

1. **车站**：点「车站」，选形式（一面一线 / 相对式 / 岛式），在空地上按住拖动定方向后点「建站」；也可以点一段直线股道在上面建站。两股道的车站两端自带渡线。
2. **铺轨**：点「铺轨」，从车站的端点出发拖动，每拖一笔定下一段，自动和前一段平滑相切；拖到另一座车站的端点会自动接上。可选一次铺两条平行股道（复线）或单条。从已有股道中间出发就是分岔，把末端拖到另一条股道上就是并线。与已有股道相交时选立体交叉或平面交叉。
3. **车辆基地**：在「车站」里选「车辆基地」，点直线股道旁边的平地。
4. **调度**：点「调度」打开总览。新建线路（在地图上依次点站）→ 购买列车 → 点线路的「＋」把列车配上去。列车沿线路往返，间隔由车数决定。
5. 点股道或车站可以查看、改名、拆除（退一半造价）。

## 操作

| 手势 | 无工具时 | 铺轨 / 建站时 |
| --- | --- | --- |
| 单指拖动 | 移动地图 | 画线 / 定车站方向 |
| 双指拖动、捏合、旋转 | 移动、缩放、旋转 | 同左 |
| 点击 | 查看股道、车站、地块 | 落点 |
| 长按 | 查看详情 | — |

顶栏右侧三个按钮：暂停、正常（1 天 ≈ 5 秒）、快进。「更多」里有回到小镇、旋转视角、设置（浅色/深色主题等）。

桌面：左键拖动，滚轮缩放，右键拖动旋转，Q/E 旋转 90°，方向键/WASD 移动，空格暂停，Esc 退出工具。
